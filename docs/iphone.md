# iPhone 捷徑與實機驗收

正式網站部署後，以 Safari 登入，使用「分享 → 加入主畫面」。網站提供 manifest 與 icon，但不支援完整離線，也尚未在實體 iPhone 上驗證。

## 分享捷徑

1. 新增捷徑，開啟「在分享表單中顯示」，接收 URL 與文字。
2. 使用「從輸入取得 URL」。若取得多個 URL，讓使用者選擇；各 App 可能傳文字、單一或多個網址，不能假設相同。
3. 若無網址，顯示「請先複製貼文或地點連結」並結束。
4. 對選定網址做 URL 編碼，組成 `你的網站網址/?url=編碼後的原始連結`，以「開啟 URL」開啟 Safari。
5. 網站會帶入快速收藏欄位。未登入時先登入，確認後按「收進口袋」。捷徑不帶密碼、cookie 或 API key，也不偷偷自動送出。

來源網址可能出現在瀏覽器歷史；捷徑只傳網址，不傳私人心得。

## 實機驗收清單

| 情境           | 檢查                                             | 狀態                                |
| -------------- | ------------------------------------------------ | ----------------------------------- |
| IG 貼文        | 是否傳出正確 URL；私人貼文／讀取限制時轉待補內容 | 等真實範例與 iPhone                 |
| Threads        | 混合文字、多 URL、threads.net／threads.com       | 等真實範例與 iPhone                 |
| Maps 地點      | 短連結、外連／App 是否正確分店                   | 等真實範例與 iPhone                 |
| Safari／主畫面 | iOS 16.4+，登入保持、返回網站                    | 等 iPhone                           |
| 操作           | 收藏、補資料、截圖、篩選、地圖、到訪、餐點與匯出 | Chromium 手機尺寸與實機結果分開記錄 |
| 檔案分享       | PDF 中文／日文、跨頁與可點連結，XLSX 多工作表    | 本機測試不能取代 iPhone 實測        |

沒有實測的來源 App 行為不以桌面結果代替。
