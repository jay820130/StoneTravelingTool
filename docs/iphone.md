# iPhone 捷徑與實機驗證

更新：2026-10-21。以 Safari 登入 [正式網站](https://stone-traveling-tool.vercel.app/)，可分享 → 加入主畫面。以下設定已配合第二階段程式更新；尚未在實體 iPhone 驗證，不將 Chromium 手機尺寸結果當作 Safari 實測。

## 分享連結並可選擇附截圖

1. 在「捷徑」新增「收進 Stone」，詳情開啟「在分享表單中顯示」，輸入類型允許 URL、文字、影像。
2. 使用「從輸入取得 URL」。一個 URL 就直接使用；多個則加入「從列表中選擇」，讓自己選正確文章／店家。沒有 URL 時用「要求輸入」貼上已複製的來源連結，取消則結束。
3. 加入「從選單中選擇」：`只收藏連結`、`連結＋截圖`。若分享輸入包含你要的影像，可先以「儲存到相簿」保存；影片不轉成圖片，也不假設來源 App 會提供圖片。
4. 對選定的原始 URL 做「URL 編碼」，組成：
   - 只收藏：`https://stone-traveling-tool.vercel.app/?url=編碼後的連結`
   - 附截圖：`https://stone-traveling-tool.vercel.app/?url=編碼後的連結&attach=1`
5. 用「開啟 URL」進入網站。未登入先登入；網站帶入連結，附圖模式自動展開「附上文字或截圖」。點「從相簿選圖」可多選，或點「拍照」。最後按「收進口袋」。
6. 網站先保存連結與圖片，再顯示等待解析。若網路中斷，不必刪掉來源重建；留在頁面重試，或到待整理重試確認／刪掉未傳完的附件再選圖。

捷徑不帶密碼、API key、cookie，不自動送出收藏。URL 會出現在瀏覽器歷史；圖片與私人文字不塞進查詢字串。**目前採「捷徑傳連結，網頁選圖」流程，並未實作可在 Safari 自動接收分享影像的原生分享擴充。** 各 App 分享輸入不同，這是可行的補充操作，尚非實機驗證結果。

## 圖片操作

新增收藏及待整理皆提供相簿多選與後鏡頭拍照 input。支援 JPEG、PNG、WebP、HEIC／HEIF，每張 5 MiB、最多 6 張、合計 12 MiB。Gemini 官方列為支援 HEIC／HEIF，因此保存原檔直接分析；iPhone 若遇不支援的顯示／辨識，先用系統截圖的 PNG 或相機 JPEG 補充，並保留錯誤代碼排查。

先選 Reels 文案、字幕畫面或 Maps 店家資訊截圖。圖片需清楚看見店名／地址；看不清楚的內容會留空或待補。已上傳圖片可查看私人截圖或刪除；若解析失敗，收藏與圖片仍保留。
