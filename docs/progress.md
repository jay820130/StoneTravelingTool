# 實作與驗證進度

更新：2026-10-18。本專案已從 README／需求文件初始化為可使用真實本機 Supabase 的應用程式；**尚未部署上線**。需求原文未修改。程式沒有假登入，也不以瀏覽器儲存取代正式資料庫。

## 已實作

私人帳號與成員資格、資料庫與附件權限、來源先存後解析、手動店家、多來源／多店關聯、候選確認、合併預覽、城市與組合篩選、自訂標籤、位置地圖、店家總評、每次到訪與餐點、XLSX／PDF 預覽及下載、持久化解析佇列與有限重試。

本機使用官方 Supabase Auth、PostgreSQL、Storage、PostgREST 與 Kong；安裝套件與 CLI、migrations、可重跑安裝腳本及啟動方式已存入專案。兩個測試帳號只存在本機，與未來私人帳號分開；所有測試來源與店名均明確標示為虛構測試資料。

## 自動驗證

- `npm run typecheck`、`npm run lint`：通過。
- `npm test`：47 項通過；包含 PostgreSQL migrations／RLS、交易、重試與復原、人工資料保留、解析失敗、SSRF 驗證、匯出及首次初始化。
- `supabase/setup/first-time.sql`：新增 5 項 PGlite 測試，驗證自動 RLS 啟用且沒有預設 Data API table grants 時仍可初始化、單一帳號授權、拒絕零／多帳號、重複執行保留原資料，以及中途失敗全數回滾。此測試使用平台 schema fixture，尚未代替使用者正式 Supabase 的實際執行驗證。
- `npm run test:e2e`：5 個流程全部通過（28.5 秒），包含桌面、手機與同一頁面登出後切換帳號的隔離回歸測試。
- `bash scripts/cloud-setup.sh`：完整重裝套件、重用本機資料庫、更新本機設定、型別／Lint／42 項測試及正式建置全部通過。
- `npm run start`：正式啟動模式的登入、PDF 下載、中文擷取、私人備註排除與手機尺寸通過；未授權 worker 呼叫回應 401。建置 trace 確認包含 PDFKit 與中文字型。
- `npm run worker`：真實本機持久化工作完成並轉為 `needs_input`，未配置 AI 時沒有假成功。
- `npm audit --omit=dev`：0 高風險／重大，2 中等項目來自同一個 uuid 間接依賴及 ExcelJS 的連帶標記。詳見架構文件。
- Codex 環境草稿已儲存安裝腳本、啟動說明、實際儲存庫位置與圖磚網域；需在環境設定中檢視、儲存並發布才會套用，尚未驗證新任務還原。
- 真實付款服務、社群文章與截圖 OCR 的準確性、iPhone、雲端排程、雲端備份復原、新 Codex 任務還原：尚未驗證。

## 剩餘外部條件與限制

1. 使用者已於 2026-10-18 完成 Supabase 建立、私人登入設定、個人 Auth 帳號及首次初始化；SQL Editor 結果截圖確認 1 個受邀帳號、10 張啟用 RLS 的 public 資料表、私人 screenshots bucket。Project URL 為 `https://cwkaosndndbzhtppvmat.supabase.co`，網站尚未連線驗證該正式專案；目前雲端開發環境對此主機的 HTTPS CONNECT 回應 403，已加入環境草稿允許清單，但尚未套用驗證。
2. 使用者尚無 Vercel 帳號，正在引導建立個人 Hobby 帳號。尚未建立部署、可登入的公開網址或雲端排程。未開通付費服務／網域；實際方案與用量費用在啟用前確認。
3. 尚無 AI key 與真實 IG、Threads、Maps 樣本。可先使用手動流程；有樣本與授權後才驗證文字／截圖解析，不把測試回應當作真實 AI 成果。
4. 位置由人工確認座標，目前沒有自動地理編碼或地點搜尋服務。一般多點會自動縮放；大量重疊點尚無群聚，仍可用清單選店。
5. OSM 只是可替換底圖的預設值；目前環境需允許圖磚主機，上線前確認政策與實際服務額度。PDF 未涵蓋的少數特殊字元顯示方框。
6. [iPhone 文件](iphone.md) 已提供分享捷徑與逐來源實測步驟，尚未在各來源 App 或 Safari 實機驗證。
